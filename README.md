# 🎓 Student Profile Generator

A simple yet dynamic JavaScript program that generates detailed student profiles using ES6 features like object destructuring, array methods, and template literals.

---

## 🚀 Overview

This project demonstrates core JavaScript concepts through the creation and display of structured student data. Each student profile includes personal and academic information, and is formatted into human-readable descriptions with gender-specific phrasing.

---

## 📌 Features

- ✅ Structured student objects with relevant attributes
- ✅ Use of ES6 object destructuring for clean and concise code
- ✅ Gender-aware sentence formatting (`He`/`She`) without clutter
- ✅ Dynamic generation of readable student descriptions using `.map()`
- ✅ Iterative display using `.forEach()` for terminal output
- ✅ Easily extendable with additional students or attributes

---

## 🧠 Concepts Applied

- Object Destructuring
- Template Literals
- Ternary Operators
- Array Methods (`map()`, `forEach()`)
- Conditional Rendering
- Clean and Readable Code Practices

---

## 🧱 Data Structure

Each student object includes the following fields:

```js
{
  firstName: 'John',

  sex: 'Male',

  courses: ['Math', 'Physics', 'Computer Science']
